# 川普關稅對半導體的影響 × AI 金融實作

國立成功大學暑期微學分課程｜2026 年 8 月 18–19 日

> 本課程為**教育性內容，不構成任何投資建議**。

## 這門課在做什麼

兩天、每天上午 3.5 小時，共 **7 小時**：

| 段落 | 時間 | 內容 |
|---|---|---|
| 演講 | 每天 1.5 小時 | 看懂川普關稅政策對半導體的影響，以及它如何牽動股市與匯率 |
| AI 實作 | 每天 2 小時 | 分組動手，做出一個**幫自己下決策的工具**，最後分組報告 |

**演講段**帶你從「川普為什麼課高關稅」一路推到「產能為什麼回美國」「美中怎麼攻防」；
**實作段**則是把這些看法變成可以驗證的東西——自己抓資料、自己畫圖、
最後讓 AI 讀你自己的資料產出一份結論報告。

## 開課前一定要做的四件事

1. **註冊 Google 帳號**——上課用來登入 Antigravity（本機開發工具），IDE 裡的 AI 助手也是同一個帳號。
2. **註冊 GitHub 帳號**——你的成果要存在這裡才帶得走（教室電腦有還原系統，下課就清空）。
3. **申請群益期貨模擬帳號（QIT）**——看國內期貨與選擇權報價，申請後要等信，**務必課前辦好**。
4. **申請群益外匯美股模擬帳號（CTA）**——看外匯與海外商品報價、使用 EvoCode，
   **與 QIT 是不同平台**，申請後要等信，**務必課前辦好**。

> 現場只登入、不註冊。十八個人同時辦帳號會吃掉半堂課。
> 詳細步驟見 [`docs/01-開課前準備.md`](docs/01-開課前準備.md)。

## 這兩天你會帶走什麼

程式會過時，流程帶得走：

```
拷問 → PLAN.md → TASK.md → MEMORY.md → 結論報告
```

- **拷問**：動手前先讓 AI 找出你還沒想清楚的地方，被問倒的就是要補的洞。
- **PLAN.md**：這個工具要做什麼、怎麼算做完。
- **TASK.md**：現在這一步，交辦給 AI 的單子（目標、材料、驗收）。
- **MEMORY.md**：做了什麼、卡在哪、AI 錯在哪、下一步——報告的素材就是它。
- **結論報告**：讓 AI 讀你自己抓的資料，產出四節報告輔助判斷。
