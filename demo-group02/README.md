# 示範成果｜第 2 組：記憶體與整合元件

> **這是給授課教師檢視的示範**，用意是呈現「一組學生兩天後應該交出什麼」。
> 分支：`demo/group02-memory-logic`，**不合併進 main**，學生看到的仍是空白起點。

## 這一組做了什麼

標的：MU（美光）、INTC（英特爾）、TXN（德州儀器）
問題：同樣是半導體，為什麼有的公司在關稅時代大漲、有的幾乎沒動？

## 交付物一覽

| 檔案 | 對應 | 說明 |
|---|---|---|
| `PLAN.md` | 六件套 | 六節規格：目標、資料、功能清單、驗收條件、除錯線索、維護方式 |
| `TASK.md` | 六件套 | 五張交辦單，含兩次「驗收不通過」的紀錄 |
| `MEMORY.md` | 六件套 | 過程紀錄：卡在哪、怎麼解決、**AI 哪裡講錯** |
| `monitor.py` | 關卡一～四 | 可重跑的工具，重跑就更新到最新交易日 |
| `raw/` | 關卡一 | 三檔原始 JSON，原封不動存檔 |
| `chart.png` | 關卡三 | 三檔相對走勢（起點＝100）＋六個事件日標記 |
| `summary.md` | 關卡四 | 一頁摘要：期間漲跌 ＋ 事件日前後五日反應 |
| `結論報告.md` | 關卡五 | 四節決策輔助報告 ＋ 四判準自檢 |
| `events.csv` | 共用素材 | 六個關稅事件日（建議由講師統一發放，六組共用） |

## 重跑方式

```bash
python -X utf8 monitor.py
```

換成別組只要改 `monitor.py` 最上面兩行：

```python
TICKERS = {"MU": "美光", "INTC": "英特爾", "TXN": "德州儀器"}
TITLE = "記憶體與整合元件：誰接單、誰買單"
```

## 這份示範想證明的三件事

1. **兩小時做得完**：抓 15 分、理 15 分、看 25 分、監控化 20 分、報告 15 分，
   合計 90 分鐘，留 30 分鐘給卡關。
2. **六組難度齊平**：程式結構完全相同，只有代號不同，評分可以直接橫向比較。
3. **題目問得出東西**：這組的資料剛好撞上三個反直覺的現象——
   關稅生效當週股價漲、利多宣布當週股價跌、政府入股當週幾乎沒反應。
   學生必須動用四判準才能誠實描述，光問 AI 得不到這些結論。
