## 講義 2 收錄了哪些文件

依序合訂自本倉庫，方便一次列印或離線閱讀：

1. `docs/00-課程架構.md`　兩天七小時的時間表與五個關卡
2. `docs/01-開課前準備.md`　四個帳號（含兩個模擬帳號的申請 QR）
3. `docs/02-環境設定.md`　開課當天的環境建置六步驟
4. `docs/03-開發流程六件套.md`　拷問流程、許願式對交辦式、commit 時機
5. `templates/PLAN.md`／`TASK.md`／`MEMORY.md`／`SETUP.md`／`HANDOFF.md`　五個範本
6. `reference/結論報告格式.md`　四節報告與合規框定
7. `reference/四判準自檢.md`
8. `reference/資料源速查.md`　七個資料源與各自的坑

> 講義 2 裡的兩個 QR 碼可以直接掃（已驗證列印解析度下可辨識），
> 用來申請課前必辦的兩個模擬帳號。

## 重新產生

兩份 PDF 由 Markdown 自動產生，內容更新後重跑即可：

```bash
python -X utf8 assets/make-handout-pdf.py
```
