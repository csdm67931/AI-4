## 文字講義（帶得走的整理，適合列印）

| 檔案 | 內容 | 頁數 |
|---|---|---|
| [`講義1-演講段.pdf`](講義1-演講段.pdf) | 要看什麼數字、去哪裡抓、四判準、怎麼分辨話術 | 4 |
| [`講義2-實作段.pdf`](講義2-實作段.pdf) | 課程架構、開課前準備、環境設定、六件套、五個範本、結論報告格式、資料源速查 | 25 |

講義 2 是本倉庫學生文件的合訂本，依序收錄：

1. `docs/00-課程架構.md`　兩天七小時的時間表與五個關卡
2. `docs/01-開課前準備.md`　四個帳號（含兩個模擬帳號的申請 QR）
3. `docs/02-環境設定.md`　開課當天的環境建置六步驟
4. `docs/03-開發流程六件套.md`　拷問流程、許願式對交辦式、commit 時機
5. `templates/` 五個範本：`PLAN`／`TASK`／`MEMORY`／`SETUP`／`HANDOFF`
6. `reference/` 結論報告格式、四判準自檢、資料源速查

> 講義 2 裡的兩個 QR 碼可以直接掃（已驗證列印解析度下可辨識），
> 用來申請課前必辦的兩個模擬帳號。

## 該看哪一份

- **上課前**：講義 2 的前三節（課程架構、開課前準備、環境設定），把帳號與環境準備好。
- **上課中**：跟著簡報走；卡住時翻講義 2 的範本與速查。
- **課後**：講義 1 是演講段的重點整理，資料源網址都在裡面，之後想自己查資料就靠它。

## 版本

線上的 Markdown 是最新版本，PDF 由它產生。若兩者有出入，以倉庫內的 Markdown 為準。
文字講義可用下列指令重新產生：

```bash
python -X utf8 assets/make-handout-pdf.py
```
