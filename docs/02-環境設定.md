# 環境設定｜開課當天現場動手的五件事

> 前提：[`01-開課前準備.md`](01-開課前準備.md) 的三個帳號都已經辦好。
> 這一頁是課堂第一節「動手建倉庫」時照著做的步驟，五件事做完，環境就緒。

## ① Colab 開啟與第一次執行

1. 登入 Google 帳號後，開啟 [colab.research.google.com](https://colab.research.google.com)。
2. 點左上角「檔案 → 新增筆記本」，會開一個空白的 `.ipynb` 檔案。
3. 在第一個程式碼格輸入一行測試程式，例如：
   ```python
   print("hello, colab")
   ```
4. 按格子左邊的執行鍵（或按 `Shift + Enter`），第一次執行需要幾秒鐘連線到運算環境，
   看到輸出 `hello, colab` 就代表環境正常。

> Colab 的運算環境不是永久保留的——長時間沒有動作或關閉分頁後，環境會重置，
> 重新整理頁面再執行一次即可，程式碼本身還在（如果已經存檔）。

## ② GitHub 建立倉庫、加組員

1. 登入 GitHub，右上角「+」→「New repository」。
2. 取一個看得懂的名稱（例如 `tariff-semi-group3`），選擇 **Public**（公開，方便組員與助教查看），
   勾選「Add a README file」。
3. 建立完成後，進入倉庫頁面，點上方「Settings」→ 左側「Collaborators」。
4. 點「Add people」，輸入組員的 GitHub 使用者名稱或註冊信箱，逐一加入。
5. 組員會收到邀請通知（信箱或 GitHub 網站上的通知），**要按接受邀請**才算真的加入。

**檢查方式**：請組員登入自己的 GitHub 帳號，打開這個倉庫的網址，確認看得到內容、
也能編輯（不是唯讀）。

## ③ Colab 存進 GitHub：Save a copy in GitHub

Colab 內建一個功能，不用打任何 git 指令就能把筆記本存進倉庫。

1. 在 Colab 裡，點上方選單「File」→「Save a copy in GitHub」。
2. 第一次使用會要求連結 GitHub 帳號，跟著畫面授權即可（授權對象是 Colab，不是外部網站）。
3. 選擇剛剛建立的倉庫，路徑可以直接放在倉庫根目錄，或建一個子資料夾（例如 `notebook/`）。
4. 下方可以填寫這次存檔的說明文字（等於一段 commit 訊息），寫清楚這次做了什麼。
5. 按「OK」，Colab 會把目前的筆記本內容存進 GitHub 倉庫，這個動作等於**一次 commit 加一次 push**。

**驗證方式**：回到瀏覽器打開自己的 GitHub 倉庫頁面，重新整理，應該會看到剛剛存進去的
筆記本檔案，點開能看到跟 Colab 上一樣的內容。

3. 安裝完成後開啟軟體，用 [`01-開課前準備.md`](01-開課前準備.md) 辦好的群益模擬帳號登入。

## ⑤ 每過一關就 commit

**這是這兩天最重要的習慣，沒有之一。**

教室電腦有還原系統，下課會清空——存在電腦桌面或本機資料夾的東西，隔天就不見。
只有存進 GitHub 倉庫的東西才是真的屬於自己的。所以：

- 完成五關卡（抓、理、看、監控化、結論報告）**任何一關**，就用 Colab 的
  「Save a copy in GitHub」存一次，或直接在 GitHub 網頁上傳檔案。
- 不要等到快下課才想起來存檔——commit 是遊戲裡的存檔點，越常存，風險越低。
- `PLAN.md`、`TASK.md`、`MEMORY.md` 三個檔案也是每次更新內容就存一次，
  不用等到寫完整份才存。

> 這個習慣的完整說明（為什麼、什麼時候做、下課前的收尾儀式）在
> [`03-開發流程六件套.md`](03-開發流程六件套.md)，這是本課程最重要的一份文件，
> 請務必花時間讀完。
